# TikTok Voice Generator

A realistic text-to-speech voice generator web application that allows users to create TikTok-style voiceovers for their videos. Generate natural-sounding audio in multiple languages and voices with an easy-to-use interface.

![Project Banner](/homePage.png)

## 🎯 Features

- **Multiple Voices**: Choose from 100+ voices including male, female, and character voices (like C3P0)
- **Multi-language Support**: Supports 20+ languages including English, Italian, Japanese, German, Spanish, Portuguese, and more
- **Instant Generation**: Create realistic text-to-speech audio in seconds
- **Audio Preview**: Listen to generated audio before downloading
- **TikTok Voice Library**: Access all TikTok voices including the popular "Siri-like" English US Female voice
- **Free Tier**: Generate up to 1000 words for free

## ⚙️ Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/jonas-kr/gessritTtv.git
   cd gessritTtv
   ```

2. **Open the project**
   - Simply open `index.html` in your web browser
   - Or use a local server for development:
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js
     npx serve
     ```

3. **Access the application**
   - Navigate to `http://localhost:8000` (or the port your server is running on)

## 💻 Usage

1. **Enter Your Text**: Type or paste the text you want to convert to speech in the text area
2. **Select Language**: Choose your preferred language from the dropdown menu
3. **Select Voice**: Pick a voice type (Male/Female/Character)
4. **Generate**: Click the "Generate" button to create your audio
5. **Preview & Download**: Listen to the preview and download when satisfied

## 📝 FAQ

**Q: Can you generate the TikTok girl voice that sounds like Siri?**  
A: Yes, choose the English US Female voice.

**Q: Can you generate the robot voice?**  
A: Yes, you can choose C3P0 in the Characters voices.

**Q: What languages are supported?**  
A: English, Italian, Japanese, German, Spanish, Portuguese and more.

**Q: What voices are supported?**  
A: This tool supports 100+ voices in 20+ languages. Sometimes TikTok doesn't show all voices in the app, you can use this tool in those cases.

**Q: How does pricing work?**  
A: You can generate up to 1000 words for free. After that you can buy credits.
